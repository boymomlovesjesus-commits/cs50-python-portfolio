## 🧪 Testing & Debugging Notes

<div align="center">

I use several techniques to test and debug my CS50P code:

- Printing intermediate values to understand program flow  
- Using `try` / `except` blocks to catch errors  
- Testing edge cases (empty input, invalid input, large values)  
- Running code multiple times with different inputs  
- Using VS Code’s debugger for step‑through execution  

As I progress to Week 5 (Unit Tests), I’ll begin writing automated tests for my projects.
