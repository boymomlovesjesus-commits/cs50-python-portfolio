# Week 0: Functions, Variables

## Overview

Week 0 introduced the fundamentals of Python programming, including variables, functions, user input, and basic string manipulation.

Through these projects, I learned how to collect input from users, process data, perform calculations, and produce output using Python.

## Projects

### indoor.py
Converts user input to lowercase text.

**Concepts practiced:**
- String methods
- User input
- Output formatting

### playback.py
Replaces spaces in text with ellipses (`...`).

**Concepts practiced:**
- String replacement
- User input
- Text manipulation

### faces.py
Converts text emoticons into emoji characters.

**Concepts practiced:**
- Functions

- Return values
