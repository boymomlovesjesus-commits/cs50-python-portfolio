# Week 0: Functions, Variables
 
## Overview
 
Week 0 introduced the fundamentals of Python programming, including variables, functions, user input, and basic string manipulation.
 
Through these projects, I learned how to collect input from users, process data, perform calculations, and produce output using Python.
 
## Projects
 
### indoor.py
Converts user input to lowercase text.
 
**Concepts practiced:**
- String methods
- User input
- Output formatting
 
### playback.py
Replaces spaces in text with ellipses (`...`).
 
**Concepts practiced:**
- String replacement
- User input
- Text manipulation
 
### faces.py
Converts text emoticons into emoji characters.
 
**Concepts practiced:**
- Functions
- String replacement
- Return values
 
### einstein.py
Calculates energy from mass using Einstein's equation:
 
E = mc²
 
**Concepts practiced:**
- Variables
- Mathematical operations
- Integer calculations
 
### tip.py
Calculates the tip amount based on a bill and percentage.
 
**Concepts practiced:**
- Type conversion
- Arithmetic operations
- Function usage
 
## Skills Learned
 
- Writing and calling functions
- Working with variables
- Accepting user input
- Manipulating strings
- Performing calculations
- Understanding Python syntax
- Debugging simple programs
 
## Lessons Learned
 
Week 0 taught me how to break problems into smaller steps and translate those steps into Python code. It also introduced me to testing programs, identifying errors, and thinking logically about program design.
