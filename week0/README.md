# Week 0 Projects

### playback.py
Replaces spaces in a string with three dots (`...`) to simulate “playback speed” formatting.

### faces.py
Converts text-based emoticons like :) and :( into their corresponding emoji characters.

### einstein.py
Converts mass to energy using Einstein’s formula E = mc².

### tip.py
Calculates a restaurant tip based on user input for cost and percentage.
