# Deep Thought

## Description

A program that responds to answers about the "Great Question of Life, the Universe, and Everything."

## Concepts Practiced

- Conditionals
- String comparison
- User input
- Case normalization

## Example

Input:

```text
42
```

Output:

```text
Yes
```

## What I Learned

This project taught me how to compare user input against multiple valid answers while accounting for different formatting and capitalization.
