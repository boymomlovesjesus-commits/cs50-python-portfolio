# Home Federal Savings Bank

## Description

A program that determines how much money to award based on the user's greeting.

## Concepts Practiced

- if, elif, else statements
- String methods
- User input validation

## Example

Input:

```text
hello
```

Output:

```text
$0
```

## What I Learned

This project helped me practice using conditional statements and handling different forms of user input.
