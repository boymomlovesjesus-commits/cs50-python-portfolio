# Week 1: Conditionals

## Overview

This week focused on using conditional statements to make decisions in Python programs. Through these projects, I practiced evaluating user input, comparing values, and producing different outputs based on specific conditions.

## Projects

### deep.py
Determines whether the user's answer matches the famous answer to the ultimate question.

**Concepts practiced:**
- String comparison
- User input
- Conditional logic

### bank.py
Calculates a value based on the user's greeting.

**Concepts practiced:**
- if, elif, else statements
- String methods
- Input validation

### extensions.py
Identifies a file's media type based on its file extension.

**Concepts practiced:**
- String manipulation
- Decision making
- Data classification

### interpreter.py
Evaluates simple arithmetic expressions entered by the user.

**Concepts practiced:**
- Mathematical operations
- Parsing input
- Conditional branching

## Skills Learned

- Writing conditional statements
- Handling user input
- Problem decomposition
- Basic debugging techniques
