# Week 2: Loops
 
## Overview
 
Week 2 focused on using loops to solve problems that require repetition, validation, and character-by-character processing.
 
Through these programs, I learned how to iterate through strings, repeatedly prompt users for input, validate data, and apply logical rules to solve increasingly complex problems.
 
## Projects
 
### camel.py
Converts a variable name from camelCase to snake_case.
 
**Concepts practiced:**
- String iteration
- Character testing
- String formatting
- Uppercase and lowercase conversion
 
### coke.py
Simulates a Coke vending machine that accepts only specific coin values and returns change.
 
**Concepts practiced:**
- While loops
- Input validation
- Conditional logic
- Running totals
 
### twttr.py
Removes vowels from user input.
 
**Concepts practiced:**
- String processing
- For loops
- Character filtering
- Conditional statements
 
### plates.py
Validates custom vanity license plates according to specific formatting rules.
 
**Concepts practiced:**
- Complex validation logic
- String indexing
- Loops
- Boolean conditions
 
### nutrition.py
Displays the calorie count of a selected fruit based on nutrition data.
 
**Concepts practiced:**
- Dictionaries
- User input normalization
- Data lookup
 
## Skills Learned
 
- Writing for and while loops
- Processing strings one character at a time
- Validating user input
- Tracking program state with variables
- Solving problems using step-by-step logic
- Debugging failed test cases
- Using check50 to verify solutions
 
## Challenges Overcome
 
During Week 2, I learned how to:
 
- Read and interpret problem specifications carefully
- Debug formatting issues that caused check50 failures
- Trace loops step-by-step to understand program behavior
- Use pseudocode to plan solutions before coding
- Handle edge cases and invalid input
 
## Favorite Project
 
**plates.py**
 
This project challenged me to combine multiple validation rules into a single solution. It helped strengthen my understanding of loops, string processing, and logical problem-solving.
